# Orbit — 个人导航工作台

一个简洁、响应式的自托管导航门户原型。包含网址收藏与搜索、分类、演示订阅列表、广告展示位、本地隐私模式和主题切换。

> 当前版本是可直接运行的前端原型：书签和偏好保存在浏览器 `localStorage` 中；RSS 内容为演示数据；广告是示例位；聊天和真实隐私浏览尚未接入。隐私模式只在页面内隐藏广告，不是 VPN、代理或匿名浏览工具，也不会隐藏 IP 地址。

## 本地运行

无需构建工具。克隆仓库后，用任意静态文件服务器打开项目根目录，例如：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。也可以部署到 GitHub Pages、Cloudflare Pages 或任意静态 Web 主机。

## 当前功能

- 响应式中文工作台界面，支持桌面和移动端
- 搜索网址、描述与分类；快捷键 `⌘ K` / `Ctrl K`
- 添加与删除网址，按分类浏览；数据保存在当前浏览器
- 自定义分类、深浅主题切换
- 本地隐私模式：隐藏广告卡片并提示隐私边界
- RSS 订阅演示区及 Miniflux 集成入口
- 广告示例卡片，便于后续替换为真实广告配置

## 后续集成建议

1. **账号与跨设备同步**：增加后端 API、认证和数据库（例如 PostgreSQL）。
2. **RSS**：自托管 Miniflux 或 FreshRSS，由后端安全地调用其 API；不要把管理密钥放在浏览器端。
3. **加密聊天**：部署 Matrix homeserver 和 Element Web，作为独立子域或新标签页入口。不要把聊天描述成端到端加密，除非实际启用并验证相关设置。
4. **广告**：建立可审核的广告配置和统计服务；隐私模式下不加载第三方广告、分析或追踪脚本，并清楚标记赞助内容。
5. **隐私**：真正的私密浏览取决于浏览器、网络与服务配置。不要把开放式网页代理集成到公共导航站；若有合法的内部代理需求，应独立部署、限制访问并做好滥用防护��
